# AmbientSounds audio assets

These unmodified Ogg files are a subset of CreativeMD AmbientSounds 6.3.10
for Minecraft 1.20.1. The source revision is
[`b2fa88dd17fb53840358ee09cb1e5c207df9f91e`](https://github.com/CreativeMD/AmbientSounds/tree/b2fa88dd17fb53840358ee09cb1e5c207df9f91e).
The source repository's LGPL-3.0 license is included as
[`AMBIENTSOUNDS-LICENSE.txt`](./AMBIENTSOUNDS-LICENSE.txt).

The original relative sound paths are preserved here. This subset includes
the rain and storm loops from the same 1.20.1 source revision. The game uses
the biome, weather, and environment loops selected by
`Client/Assets/game/ambientProfiles.js`.
