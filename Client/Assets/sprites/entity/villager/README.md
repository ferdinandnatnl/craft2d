`farmer.png` is the vanilla Minecraft 1.12.2 farmer atlas kept as a fallback,
copied from [`assets/minecraft/textures/entity/villager/farmer.png`](https://github.com/InventivetalentDev/minecraft-assets/blob/1.12.2/assets/minecraft/textures/entity/villager/farmer.png).
The `villager.png`, `type/`, `profession/`, and `profession_level/` layers are
unmodified Minecraft Java 1.20.1 client textures. The client combines these
64×64 layers to show the villager's biome, job, and trade rank.

The same textures and the villager sound files are listed in
[`docs/third-party-assets.md`](../../../../../docs/third-party-assets.md).
