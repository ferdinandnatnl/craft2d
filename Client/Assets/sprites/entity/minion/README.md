`as_entityminion.png` is the Minion model texture from AtomicStryker's
Minecraft Minions 1.12.2 release. It is used with a 2D articulated model based
on that release's `ModelMinion` dimensions and texture regions. The matching
Master Staff icon is in [`../../items/minion/masterstaff.png`](../../items/minion/masterstaff.png).

Source: [Minecraft Minions 1.12.2](https://www.curseforge.com/minecraft/mc-mods/minecraft-minions/files/2497432)
