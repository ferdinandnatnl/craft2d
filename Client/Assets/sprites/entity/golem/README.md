# Iron golem model assets

These assets use Mojang's Minecraft Bedrock sample iron golem model and texture:

- [Geometry](https://github.com/Mojang/bedrock-samples/blob/main/resource_pack/models/entity/iron_golem.geo.json)
- [Texture](https://github.com/Mojang/bedrock-samples/blob/main/resource_pack/textures/entity/iron_golem/iron_golem.png)

Keep the geometry UV layout and texture atlas paired when updating either file.
