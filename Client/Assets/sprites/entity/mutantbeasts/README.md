# Mutant Creatures Legacy assets

The character texture atlases and item textures in this folder and the matching
`items/mutantbeasts` folder come from the official
[Mutant Creatures Legacy repository](https://github.com/Elite-Modding-Team/MutantCreaturesLegacy).
The character UVs and cuboid positions are translated from its mutant model
classes in `Client/Assets/entities/mobs/mutantModelBodies.js`.

The upstream `LICENSE` and `LICENSE_ASSETS` files are included here. Keep those
notices with these textures.

The mutant sound files under `Client/Assets/audio/sfx/mobs/mutant_*` come from
the same repository and keep the upstream license notices alongside them.
